# SolidWorks 鼠标旋转 / 平移脚本 (AutoHotkey v2)

改变 SolidWorks 的鼠标操作习惯，让视图操控更顺手：

| 操作 | 效果 |
|------|------|
| **右键按住拖动** | 旋转视图 |
| **中键按住拖动** | 平移视图 |
| 右键轻点（不移动） | 正常右键菜单 |
| 中键轻点（不移动） | 默认中键单击 |

只对 SolidWorks（`SLDWORKS.exe`）生效，**不影响其他任何软件**。

## 用法

直接双击 `SW_RightButtonRotate.ahk` 即可启动（前提：本机已安装 [AutoHotkey v2](https://www.autohotkey.com/)）。
任务栏托盘区出现绿色 **H** 图标表示已生效。

如需开机自启，把脚本（或指向它的快捷方式）放进 Windows「启动」文件夹即可。

## 暂停 / 退出

- **`Ctrl + Win + R`**：临时暂停 / 恢复（应急恢复系统默认鼠标行为）。
- 右键托盘区绿色 H 图标 → **Exit**：彻底退出。

## 原理

SolidWorks 本身不支持把右键设为旋转（默认中键=旋转、右键=菜单）。本脚本用 AutoHotkey
把「右键拖拽」实时翻译成「中键拖拽」、「中键拖拽」翻译成「Ctrl+中键拖拽」（平移），
移动阈值 4 像素用于区分「拖拽」和「轻点」，从而保留右键菜单。

## 注意事项

- 需要 AutoHotkey **v2**（脚本头部有 `#Requires AutoHotkey v2.0`）。
- 如果 SolidWorks 以「管理员身份」运行，脚本也需以管理员身份运行，否则会被系统 UIPI 拦截而失效。
